# Repository operating instructions

This repository is a public OpenAlex research skill and client implementation.

## Source and release boundary

Use an isolated task branch and reviewable PR. Read the exact current main base
and only the files needed for the task. Run applicable secretless checks; keep
API credentials, personal context and private data outside source and test
artifacts. Reviewed main is the release source. A merge does not prove a website,
installed skill or client deployment has adopted it; verify the actual consumer
before claiming that outcome.

## Estate-related work

`pqexpert/FungibleRD-MVP/docs/llmlms/PQEXPERT-PRINCIPAL-OPERATING-GUIDE.md` and
`docs/llmlms/sops/SOP-003-REPOSITORY-ADMISSION-AND-PROJECTION.md` through the
existing permitted source route. Shared account ownership does not make this
public source a Fabric Actor or grant production/provider-write authority.

The automatic Duck Actor publisher does not target this repository. Trusted
maintenance review and this repository's own publication route are separate.
Preserve its existing licensing, public/private boundary and domain ownership.
